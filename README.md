# AI Open Source Hub：AI 工具与使用资源

[English](README.en.md)

把值得用的 AI 工具整理成真正能上手的独立项目：先知道它做什么，再让 AI 协助选择下载资源、安装、配置和完成第一个任务。每个项目都有自己的教程、截图、Skills、提示词与许可说明。

## 项目目录

| 项目 | 解决什么问题 | 本地资源 | 官方入口 |
| --- | --- | --- | --- |
| **aimeGeo** | 自研免费 GEO 系统，做 GEO，也做自媒体：AI 创作、多平台发布与按需引用检测 | [aimeGeo 使用资源](https://github.com/xxjrq/aimegeo) | [官网](https://geo.aimmme.com/) · [客户端下载](https://geo.aimmme.com/download/) · [帮助](https://geo.aimmme.com/docs/) |

机器可读目录见 [catalog.json](catalog.json)。独立项目放在 `projects/<项目名>/`；发布时以独立 GitHub 仓库管理，再由总目录关联，安装者不必下载其他项目。

## 让 AI 帮你开始

将下面的话与所选项目的 README 一起交给 Codex、Claude Code、WorkBuddy 或熟悉的 AI 助手：

```text
先读这个项目的 README 和安装指南。说明它能解决什么问题，识别我的操作系统，选择官方资源，协助我下载、安装，并完成一个最小使用示例。不要把教程资源包误当成产品安装包，不要改动无关项目或公开我的账号资料。
```

## 每个项目应包含什么

- 明确的用途、适用人群和当前能力。
- 经核对的官方资源链接，下载和安装步骤。
- 能独立复制使用的提示词与标准 `SKILL.md`。
- 不包含真实账号、客户内容的实拍截图与示例。
- 中文说明、英文入口、FAQ 和许可范围。

新增项目规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。仓库许可证仅覆盖本目录原创的开放资源；各产品及第三方素材遵循各自许可。
