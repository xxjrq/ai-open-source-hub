# AI Open Source Hub

[简体中文](README.md)

A collection of independent AI tool guides and practical resource packs. Each project explains what the product does, where to obtain official downloads, how to install it, and how to complete a first task with an AI assistant. Guides include screenshots, reusable prompts and Agent Skills.

| Project | Purpose | Resources | Official product |
| --- | --- | --- | --- |
| aimeGeo | Free GEO and creator workflows: AI content, multi-platform publishing and optional citation checks | [Usage resource pack](https://github.com/xxjrq/aimegeo) | [Website](https://geo.aimmme.com/) · [Downloads](https://geo.aimmme.com/download/) · [Help](https://geo.aimmme.com/en/docs/) |

See [catalog.json](catalog.json) for the machine-readable catalog and [CONTRIBUTING.md](CONTRIBUTING.md) for the project format. Individual projects live under `projects/` and have their own repositories and license boundaries. A guide repository does not imply that an entire commercial product is open source.
